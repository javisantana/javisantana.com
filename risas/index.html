javisantana.com / risas

Una web seria necesita una parodia seria

Este directorio contiene versiones alternativas del sitio de Javi Santana: divertidas, un poco pasivo-agresivas, hechas para reírse un poco de alguien que se toma la vida profesional demasiado en serio. (Con cariño. Siempre.)

¿Qué es esto?

risas es un experimento: distintos agentes de IA leen el sitio real de javisantana.com, su Substack, sus posts y sus redes, y generan una landing alternativa en HTML plano (vanilla CSS + JS).

El tono está definido en prompt.md: humor, buen rollo, diseño un poco loco, y esa puntita pasivo-agresiva que solo funciona cuando el objetivo es tu propio fundador/CEO/notario-en-crisis.

La web oficial sigue siendo la de siempre. Esto es el backstage con confeti y sarcasmo.

Versiones disponibles

Cada agente interpreta el mismo brief a su manera. Elige tu veneno:

  • Javi Santana™ — Professional Seriousness, Cathedral-Grade Grok · actual

    Rediseño completo: grid pixelado, KPIs, modos Builder/CEO/LinkedIn Serious™, simulador de notario y lluvia de SQL.

  • El Hombre Que Toma Todo Demasiado En Serio Claude

    Estética cómic/marquee rojo, cursor 🤓, breaking news infinita y Serious Mode™ con Times New Roman corporativo.

  • Seriousness Audit Codex

    Look tipo auditoría en papel crema: colores chillones, métricas de seriedad y energía de informe que nadie pidió.

Cómo se genera

El flujo vive en este mismo directorio:

  1. prompt.md — instrucciones para el agente: fuentes permitidas, tono, nombre del HTML de salida, tracking.
  2. run.sh — lanza Claude, Codex y Grok en secuencia; cada uno lee el prompt y escribe su <agent-name>.html.
  3. git commit — al terminar, se commitean los HTML nuevos con el mensaje “new version of javisantana.com/risas”.

Regla importante del prompt: los agentes no leen otros archivos de risas/ salvo prompt.md. Sí pueden leer el resto del repo y la web para sacar material.
